# 06. 대시보드 화면 범위

사용자: 운영자 1~2명(최윤서 본인 + 보조). 공개 서비스가 아니다 → 로그인은 운영자 계정만. [호스팅: D3 확정 — MVP 는 Windows 실행기 + SQLite. 인증 방식은 미정]

## MVP 화면

| 화면 | 목적 | 주요 동작 |
| --- | --- | --- |
| **파이프라인 보드** | 모든 편을 상태(02 SOP)별 칸으로 | 카드 클릭 → 편 상세. 막힌 편(실패·반려) 강조 |
| **이벤트 캘린더** | 다가오는 이벤트와 게시 예정 | 이벤트 추가·수정, "이 이벤트로 편 만들기"(→ selected) |
| **편 상세 — 원고 편집기** | 5단 원고 + 운영자 해석 입력 | 단별 글자 수 표시, 금지 표현 경고(block/warn), 저장 시 `drafted` |
| **편 상세 — 출처 표** | 주장별 출처·원문 인용 | 출처 추가, 링크 확인 결과, 「현재 시장은 무엇을 예상하는가」단 "재확인 필요" 표시 |
| **편 상세 — 미리보기** | 렌더된 카드 7장 + Shorts + 캡션 | 휴대폰 크기 미리보기, 재렌더 |
| **검수** | 사람 승인 게이트 | 체크리스트, 승인/반려(사유 필수), 승인 해시 표시 |
| **게시** | 승인본 내보내기·게시 | MVP: 업로드 묶음 다운로드 + 캡션 복사 + 게시 URL 수동 입력 |
| **성과** | 편별 지표 | 수동 입력 폼, 편별·포맷별 표 |
| **프리셋** | 현재 활성 프리셋 확인 | 읽기 전용(변경은 Git 으로), 스키마 오류·`TBD` 잔존 경고 |

## 자동화 단계에서 추가

- 이벤트 후보함(자동 수집 결과 → 수락/무시)
- 게시 작업 큐(예약 시각·상태·재시도·실패 로그)
- 계정 연결 상태(토큰 만료일 표시 — 토큰 값 자체는 화면에 절대 표시하지 않음)
- 성과 자동 수집 + 프로필 방문→팔로우 추이

## 화면 원칙

- 화면은 유스케이스만 호출한다(04 문서). 화면에서 외부 API 직접 호출 금지.
- 프리셋은 대시보드에서 편집하지 않는다(정본은 Git — 01 문서). 편집 UI 는 필요성이 실측되면 별도 결정.
- 대시보드 UI 언어: 운영자 언어(한국어/영어) [결정 필요 D9]. 콘텐츠 미리보기는 발행 언어(프리셋, 기본 영어·미확정 [결정 필요 D10])로 보여준다.
