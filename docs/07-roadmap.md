# 07. 로드맵 — MVP → 자동화

각 단계는 "완료 기준"을 통과해야 다음으로 간다. 기간은 추정하지 않는다(실측 후 기입).

## M0. 설계 승인 (이 PR)
- 완료 기준: 08 문서의 D1·D2·D3 결정, 문서 승인.

## M1. 수동 한 편 (코드 최소)
- 목표: 첫 포맷 `pre-event-5` 로 **실제 이벤트 한 건**을 끝까지 손으로 만든다 → 공정·글자 수·카드 디자인 실측.
- 범위: 프리셋 스키마 + 카드 템플릿 + 로컬 렌더 CLI. 대시보드 없음.
- 완료 기준: 카드 7장이 렌더되고 사람 검수 통과, 실제 소요 시간을 단계별로 기록.
- 선결: 브랜드 이름·캐릭터는 자리표시자 가능(게시 차단 규칙 때문에 실제 게시는 확정 뒤).

## M2. MVP 대시보드
- 범위: `domain`·`application`·`storage`·`render-html`·`video`(자막만)·`publisher-manual`·`apps/dashboard`.
- 화면: 06 문서 MVP 목록 전부.
- 완료 기준: 이벤트 입력 → 원고 → 출처 → 렌더 → Shorts → 승인 → 업로드 묶음 → 성과 수동 입력이 대시보드에서 끊김 없이 3편 연속 돈다. 승인 없는 게시 시도가 도메인 규칙으로 막히는 테스트 통과.

## M3. 게시 연동
- 선결: Instagram 프로페셔널 계정·Meta 앱, YouTube OAuth 프로젝트(사람이 생성 — 이 설계 범위 밖), 공개 이미지 호스팅.
- 범위: `publisher-instagram`, `publisher-youtube`(비공개 업로드), 게시 작업 큐, 토큰 만료 알림.
- 완료 기준: 승인된 편이 예약 시각 ±10분 안에 게시되고 외부 ID 가 기록됨. 실패 시 재시도 1회 후 알림.

## M4. 소재·성과 자동화
- 범위: 공식 캘린더 수집 → 후보 제안, 성과 API 수집, (선택) LLM 원고 초안, (선택) TTS.
- 완료 기준: 후보 제안 적중(사람이 채택한 비율)과 운영 시간 절감을 M2 대비 실측.

## M5. 포맷 확장
- 두 번째 포맷(예: 발표 다음날 "무엇이 맞았나" 회고형) 을 프리셋 + 템플릿 추가만으로 운영 — 코드 변경 없이 되는지가 설계 검증 기준.
