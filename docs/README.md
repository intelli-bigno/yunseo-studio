문서는 한국어다. 게시물 발행 언어는 미정이며 프리셋 값이다(기본 영어, 사용자 확정 전 — D10).

## 읽는 규칙

- `[미검증]` 표시는 공식 문서·실측으로 아직 확인하지 않은 가정이다. 구현 전 해당 단계에서 실측으로 확인한다.
- `[결정 필요]` 표시는 [08-decisions.md](08-decisions.md) 의 항목 번호와 연결된다.
- 원문(00)과 정리본이 다르게 읽히면 원문이 맞다.
- 투자 관련 문구(면책·고지 포함)는 이 문서에서 **확정하지 않는다**. 예시는 모두 `초안`이다.

## 범위 밖

- 구현 코드, 외부 계정(Instagram·YouTube) 생성·접속, 비용 발생 작업.
- 다른 개인 프로젝트(noa 계열)의 코드·자산·계정 공유. 선례는 구조만 참고한다.
