# 01. 콘텐츠 정본(SoT, Source of Truth)과 프리셋

## 1. 원칙

- **바뀌지 않는 것(편집 정본)**과 **바뀌는 것(프리셋)**을 파일로 나눈다.
- 브랜드 이름·캐릭터는 아직 미정이다. 코드·템플릿은 이름을 직접 쓰지 않고 프리셋 키만 참조한다.
  확정되면 **프리셋 파일 교체만으로** 전 게시물·대시보드에 반영된다.
- 정본은 Git 에 있는 텍스트 파일(YAML/Markdown)이다. DB 는 정본을 복제하지 않고 "어느 프리셋 버전으로 만들었나"(버전 해시)만 기록한다.

## 2. 편집 정본 (확정 — 바꾸려면 사람 승인)

| 항목 | 값 |
| --- | --- |
| 컨셉 | 시장을 읽는 안목을 기르는 투자 매거진 |
| 독자 정체성 | 나는 세상의 흐름에 관심이 있고, 내 기준으로 판단한다 |
| 타겟 | 투자 경험은 있지만 자신만의 해석을 더 갖고 싶은 사람 |
| 초기 목표 | 프로필·최근 게시물만 보고도 관점과 취향이 느껴져 팔로우하고 싶게 |
| 증거(매 게시물이 보여줄 것) | 사건 전후 시나리오 · 본인 해석 · 직접 써볼 자료와 도구 |
| 게시 언어 | 영어 |

### 편집 원칙 (정본에서 도출 — 검수 체크리스트로 쓴다)

1. **해석을 주되 결론을 강요하지 않는다.** "사라/팔아라"가 아니라 "이 신호가 나오면 이렇게 읽을 수 있다".
2. **시나리오는 항상 둘 이상.** 한 방향 예측 금지.
3. **모든 수치·사실은 출처가 있다.** 출처 없는 문장은 렌더 단계로 못 넘어간다(→ 02 SOP 3단계).
4. **독자가 손에 쥘 것 하나.** 체크리스트·지표 이름·공식 자료 링크 중 하나 이상.
5. **투자 권유로 읽힐 수 있는 표현은 검수 게이트에서 사람이 판정한다.** 금지어·고지 문구는 컴플라이언스 프리셋(§3.5)에 있으나 **현재 미확정**.

## 3. 프리셋 (교체 가능)

```
presets/
  brand/        brand.default.yaml      이름·핸들·색·서체·로고 경로·URL
  character/    character.default.yaml  화자(사람/캐릭터/익명 에디터)·말투·외형 참조
  tone/         tone.default.yaml       문장 길이·어휘 수준·금지 표현·이모지 정책
  format/       pre-event-5.yaml        포맷 정의(슬롯·글자 수·카드 수·Shorts 길이)
  compliance/   compliance.draft.yaml   고지 문구·금지어(초안, 미확정)
  active.yaml                           지금 쓰는 프리셋 조합(파일 이름만 가리킴)
```

- 모든 프리셋은 스키마(형식 정의)로 검증한다. 필드 누락 시 렌더·게시 차단.
- `active.yaml` 만 바꾸면 조합이 바뀐다. 게시물은 만들 때의 프리셋 버전(Git 커밋 해시)을 기록하므로 과거 게시물은 재현 가능하다.
- 이름·캐릭터 미정 상태에서는 `brand.default.yaml` 의 `name: "TBD"` 같은 자리표시자로 돌린다. 자리표시자가 남아 있으면 **게시 단계에서 차단**한다(실수로 TBD 가 나가지 않게).

### 3.1 brand (예시 필드)

```yaml
id: default
name: TBD            # 미정 — 게시 차단 조건
handle: TBD
palette: { bg: "#FFFFFF", ink: "#111111", accent: "#TBD" }
typeface: { display: TBD, body: TBD }
logo: assets/brand/TBD.svg
```

### 3.2 character

화자 형태 자체가 미정이다: ①최윤서 본인 얼굴·이름 ②캐릭터(일러스트·AI) ③익명 에디터 목소리. → [결정 필요 D7]
프리셋은 세 형태를 모두 담을 수 있게 `kind: person | illustrated | editor` 로 둔다.

### 3.3 tone (예시)

```yaml
voice: "calm, curious, second-person, no hype"
reading_level: "B2"          # 영어 비원어민도 읽히는 수준 [미검증 — 타겟 언어권 확인 필요]
banned_phrases: ["guaranteed", "can't lose", "to the moon"]   # 초안
emoji: none
```

### 3.4 format — 첫 포맷 `pre-event-5` (이슈·발표 전날 카드뉴스)

예: *Three things markets will re-price after the US midterms* (초안 제목).

| 카드 | 슬롯 | 담는 것 | 증거 연결 |
| --- | --- | --- | --- |
| 0 | cover | 훅 제목 + 이벤트 일시(시간대 명시) | — |
| 1 | why_it_matters | 왜 중요한가 — 이 이벤트가 바꾸는 변수 하나 | 본인 해석 |
| 2 | scenarios | 결과별 시나리오 (2~3개, 각 1줄) | 사건 전후 시나리오 |
| 3 | transmission | 시장 전달 경로 — 결과 → 금리·달러·섹터 등 경로 | 본인 해석 |
| 4 | priced_in | 이미 반영된 기대 — 시장이 현재 가정하는 것(수치는 출처 필수) | 출처 |
| 5 | signals_after | 발표 이후 볼 신호 — 독자가 직접 확인할 지표·자료 | 직접 써볼 자료 |
| 6 | sources | 출처 목록 + 고지(초안) | 출처 |

- 카드 수 7장(표지·본문 5·출처). Instagram 캐러셀 상한 안이다(상한 값은 05 문서 참조).
- 슬롯마다 글자 수 상한을 프리셋에 둔다(예: 본문 카드 ≤ 220자 [미검증 — 시안 렌더로 조정]).
- Shorts 변환 규칙도 같은 포맷 파일에 둔다: 슬롯 1·2·5 를 축약한 30~45초 세로 영상(02 SOP 5단계).

### 3.5 compliance (초안 — 확정 금지)

- 고지 문구 예시(초안): *"For education only. Not investment advice."* — 실제 문구는 사람이 정한다. [결정 필요 D8]
- 어느 법역(한국·미국 등)의 규제를 기준으로 할지 미정. 무료 일반 정보 제공과 유료 자문의 경계는 법률 검토 대상이다. [미검증]

## 4. 선례에서 가져온 것 (구조만)

- dotfiles `ig-carousel` 스킬: "캐러셀은 한 가지 질문을 끝까지 밀어붙이는 논증", "정본은 한 곳, 사본 금지", "서사 확정에서 사람 승인 뒤 비용 단계로" — 원칙만 채택.
- 코드·조판 키트·자산·계정은 반입하지 않는다.
