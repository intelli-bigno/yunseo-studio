# 01. 콘텐츠 정본(SoT, Source of Truth)과 프리셋

원문은 [00-brief-original.md](00-brief-original.md) 에 그대로 보존했다. 이 문서는 그 정리본이다.
원문과 다르게 읽히면 원문이 맞다.

## 1. 원칙

- **바뀌지 않는 것(편집 정본)**과 **바뀌는 것(프리셋)**을 파일로 나눈다.
- 브랜드 이름·캐릭터·발행 언어는 아직 미정이다. 코드·템플릿은 이름을 직접 쓰지 않고 프리셋 키만 참조한다.
  확정되면 **프리셋 파일 교체만으로** 전 게시물·대시보드에 반영된다.
- 정본은 Git 에 있는 텍스트 파일(YAML)이다. DB 는 정본을 복제하지 않고 "어느 프리셋 버전으로 만들었나"(버전 해시)만 기록한다.

## 2. 편집 정본 (확정 — 바꾸려면 사람 승인)

| 항목 | 값 |
| --- | --- |
| 컨셉 | 세계의 변화와 시장을 연결하고, 다가올 사건의 파급효과를 미리 짚는 투자 매거진 |
| 핵심 문장 | 세계의 변화에서, 시장의 다음 질문을 찾습니다. |
| 다루는 것 | 주요 경제·정치 이벤트의 시나리오와 시장 영향, 트레이딩 관점, 연구 |
| 차별점 | 자료 조사에 **운영자의 도메인 지식·경험**을 더해 고유 해석을 쌓는다 |
| 최우선 목표 | **팔로우하고 싶은 매체** — 팔로워가 "좋은 정보원을 알고, 흐름을 읽고, 자기 관점으로 판단하는 사람"처럼 느끼게 한다 |
| 브랜드 인상 | 차분함 · 안목 · 신뢰감 · 접근성. 읽기 쉽되 새로운 연결과 생각할 거리를 준다 |
| 알파(차별 가치) | 많이 말하기가 아니라 **선별과 해석의 깊이** |
| 타겟 | 국가가 아닌 **관심사·태도**로 정의한다 — 경제·정치·시장 흐름에 관심 있고, 자기 판단 기준을 만들고 싶은 독자. 한국 한정 아님 |
| 초기 목표 | 프로필과 최근 게시물만 보고도 관점·취향이 느껴져 팔로우 |
| 이후 목표 | 사건 전후 분석·연구로 재방문 · 저장 · 공유할 이유를 만든다 |
| 시각 | 절제된 색 · 선명한 타이포 · 읽기 쉬운 차트 · 일관된 표지 |
| 발행 언어 | **미정** — 프리셋 값. 기본값은 영어(이전 전달)이며 사용자 확정 전이다 → [결정 D10] |

### 금지 표현 (확정 — 데이터는 `presets/compliance/banned-expressions.yaml`)

| 표현 | 적용 범위 | 처리 |
| --- | --- | --- |
| 「무료」 「수익 보장」 「비밀 정보」 「무조건」 | 본문·캡션·카드·브랜드 문구 전부 | block (게시 불가) |
| 「지표」 | **브랜드 전면 홍보 문구**(이름·소개·한 줄 설명 등)만. 본문에서는 일반 용어로 쓸 수 있다 | block |
| 위 표현의 영어 대응(예: guaranteed return, insider information) | 발행 언어가 영어일 때를 대비한 **제안** | warn — 사람이 확정하기 전까지 막지 않고 알린다 → [결정 D11] |

검사는 코드(`packages/domain` 의 `findBannedExpressions`)와 테스트로 강제한다. 공백·전각·제로폭 문자로 피할 수 없게 정규화해서 비교한다.

### 편집 원칙 (정본에서 도출 — 검수 체크리스트로 쓴다)

1. **해석을 주되 결론을 강요하지 않는다.** "사라/팔아라"가 아니라 "이 신호가 나오면 이렇게 읽을 수 있다".
2. **시나리오는 항상 둘 이상.** 한 방향 예측 금지. (스키마가 강제)
3. **모든 수치·사실은 출처가 있다.** 출처 없는 수치는 `verified` 로 못 올라간다. (스키마가 강제)
4. **독자가 손에 쥘 것 하나.** 발표 이후 직접 확인할 신호·자료 하나 이상. (5단 중 마지막 단)
5. **운영자 해석을 비워 둔 채 검수로 보내지 않는다.** 자료 조사만으로는 차별점이 없다. (스키마가 강제)
6. **투자 권유로 읽힐 수 있는 표현은 검수 게이트에서 사람이 판정한다.** 고지 문구는 아직 미확정이다 → [결정 D8]

## 3. 프리셋 (교체 가능)

```
presets/
  active.yaml                         지금 쓰는 조합 (파일 경로만 가리킴)
  brand/brand.default.yaml            이름·핸들·컨셉·핵심 문장·색·서체·로고·시각 규칙
  character/character.default.yaml    화자 형태(미정)·말투·외형 참조
  tone/tone.default.yaml              목소리·원칙·읽기 수준·이모지
  language/language.default.yaml      발행 언어(기본 en, 미확정)·운영자 UI 언어
  format/pre-issue-5.yaml             포맷 ① 이슈 이전 (5단, 카드 7장)
  format/post-issue-research.yaml     포맷 ② 이슈 이후 (자리만)
  compliance/banned-expressions.yaml  금지 표현 규칙 데이터
```

- 모든 프리셋은 스키마(`packages/presets-schema`)로 검증한다. 필드 누락·형식 오류면 로드가 실패한다.
- `active.yaml` 만 바꾸면 조합이 바뀐다. 로드 결과에는 프리셋 파일 내용의 sha256(`versionHash`)이 붙는다.
- **자리표시자(`TBD`)**: 이름·핸들·서체·강조색·로고·화자 이름이 미정이라 값이 `TBD` 다. 하나라도 남아 있으면 `validate --publish` 가 실패한다(게시 단계 차단 규칙).
- 색은 잠정값(흰 배경·검정 글자·회색·강조색 TBD)이다. 브랜드 확정 때 교체한다.

### 화자 (character)

화자 형태 자체가 미정이다: ①최윤서 본인 얼굴·이름 ②캐릭터(일러스트·AI) ③익명 에디터 목소리. → [결정 D7]
프리셋은 `kind: undecided | person | illustrated | editor` 로 담는다.

## 4. 포맷

### 4.1 포맷 ① 이슈 이전 `pre-issue-5` (활성)

**대상 사건**: 기대를 바꿀 사건 — CPI · FOMC · 선거 · 주요 정책 발표 · 예정 연설 등. 선별이 곧 가치다.
**발행 시점**: 기본 **전날**. 복잡한 사건은 그보다 앞서 **배경 설명** 게시물을 먼저 낸다.

| 단 | 키 (`STAGE_KEYS`) | 질문 | 담는 것 |
| --- | --- | --- | --- |
| 1 | `why_it_matters` | 왜 중요한가 | 이 사건이 바꾸는 변수 |
| 2 | `market_expectation` | 현재 시장은 무엇을 예상하는가 | 이미 가격에 담긴 기대 (수치는 출처 필수) |
| 3 | `scenarios` | 결과별 시나리오 | 둘 이상, 각각 조건 → 읽는 법 |
| 4 | `transmission` | 어떤 경로로 자산·업종에 영향을 주는가 | 결과 → 금리·환율·업종 등으로 닿는 길 |
| 5 | `after_checks` | 발표 이후 무엇을 확인할 것인가 | 독자가 직접 확인할 신호와 볼 곳 |

카드는 표지 + 5단 + 출처 = **7장**. 글자 수 상한(본문 카드 ≤ 220자 등)은 시안 렌더 전 가정값이라 프리셋에 `limits_provisional: true` 로 표시했다.
Shorts 변환 규칙(어느 단을 축약할지)은 첫 편을 만들어 본 뒤 정한다.

**정본 스키마**: `packages/domain/src/content/pre-issue.ts` (`pre-issue-5/v1`). 필드는 YAML 키 그대로다.
예시: `content/examples/pre-issue/us-midterms-three-repricings.yaml` — 사실 수치 0, 일시·시간대·운영자 해석은 자리만 둔 `draft`.

`draft` → `verified` 로 올리려면 `verificationBlockers(card)` 가 비어야 한다:
일시·시간대 기입, 운영자 해석 기입, 모든 claim 에 출처(url·접근일·원문 인용), 본문 수치마다 claim.

### 4.2 포맷 ② 이슈 이후 `post-issue-research` (자리만)

사건 이후 분석·연구. 재방문·저장·공유 이유를 만드는 포맷이다. 단계·카드 구성은 **미정**이라 프리셋에 `status: reserved` 로 자리만 있다.
설계는 첫 이슈 이전 편이 나간 뒤 별도 결정으로 한다. → [결정 D12]

## 5. 컴플라이언스 (초안 — 확정 금지)

- 고지 문구 예시(초안): *"For education only. Not investment advice."* — 실제 문구는 사람이 정한다. [결정 D8]
- 어느 법역의 규제를 기준으로 할지 미정. 정보 제공과 자문의 경계는 법률 검토 대상이다. [미검증]
- 투자 권유·수치 단정 문구는 이 저장소의 예시·문서에 넣지 않는다.

## 6. 선례에서 가져온 것 (구조만)

- dotfiles `ig-carousel` 스킬: "캐러셀은 한 가지 질문을 끝까지 밀어붙이는 논증", "정본은 한 곳, 사본 금지", "서사 확정에서 사람 승인 뒤 비용 단계로" — 원칙만 채택.
- 코드·조판 키트·자산·계정은 반입하지 않는다.
