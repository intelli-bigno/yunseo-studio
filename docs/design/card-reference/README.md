## 2. 분해표

수치는 1080 px 폭 기준으로 캡처를 눈으로 잰 값(≈, ±8 px / ±10 %)이다. 서체명은 확인할 수 없어 분류만 적는다 [미확인].

### 2.1 장별 역할

| 장 | 역할 | 구성 |
| --- | --- | --- |
| 1 | **표지** | 사진 전면 + 큰 흰 제목 2줄(하단 1/4, 수치로 시작하는 질문형) + 상단 좌 협업 로고 · 상단 우 편집 크레딧 원 · 하단 중앙 계정 표시 |
| 2~8 | **본문 7장** | 위 ≈50 % 사진(아래로 흰색 페이드) → **질문 말풍선(좌) / 답 말풍선(우)** → 글 영역. 장마다 질문 하나. 2장=정체와 규모(번호 목록 상자), 3장=왜 이제야 알려졌나, 4장=비교 대상, 5장=차이점, 6장=사람(흑백 인물), 7장=출발 이야기, 8장=지금의 방식과 인용 |
| 9 | **마무리** | 종이색 바탕(사진 없음) + 질문/답 말풍선이 위로 이동 + 문단 4 + 가는 선 + 검정 하이라이트 상자의 닫는 인용 |

차트·그래프·표 장은 **없다**. 정보 구조는 「질문 → 한 줄 답 → 근거 문단」이다.

### 2.3 타이포 위계

| 층 | 크기(≈) | 굵기 | 쓰임 |
| --- | --- | --- | --- |
| 표지 제목 | 86 px | 굵음 | 사진 위 흰색, 숫자 + 질문 |
| 질문·답 말풍선 | 34 px | 중간~굵음 | 「Q.」「A.」 접두 + 이모지 1개 |
| 본문 | 32 px | 보통 | 해요체 짧은 문장, 줄바꿈은 의미 단위 |
| 강조 | 32 px | **굵음 + 밑줄** | 크기를 키우지 않고 굵기·밑줄로만 강조 |
| 인용 | 32 px | 보통 / 굵음 | “ ” 로 시작, 한 줄 들여쓰기 걸이 없음 |

- 서체는 한 가족(산세리프, 한글 기하 계열로 보임)을 굵기로만 나눈다 [서체명 미확인].
- 크기 비율 ≈ **표지 2.7 : 말풍선 1.06 : 본문 1** — 본문과 말풍선은 크기 차이가 거의 없고 **상자 모양·굵기**로 위계를 만든다.

### 2.4 색

| 구분 | 값(≈) | 쓰임 |
| --- | --- | --- |
| 잉크 | 검정 | 글자 · 말풍선 테두리 · 브랜드 상자 · 닫는 인용 하이라이트 |
| 바탕 | 흰색 / 종이색(9장, 가는 질감) | 글 영역 · 마무리 장 |
| 강조 1색 | 탄(≈#C99B6B) | 답 말풍선 채움 · 번호 목록 상자 테두리 · 가는 선 |
| 사진 | 적갈색 벽돌·자연광 톤으로 통일 | 표지·본문 상단 |

**시스템 색은 3개(검정·흰/종이·탄) + 사진.** 우리 시각 시스템의 「바탕·글자·보조 회색·선·강조 1색」과 같은 문법이다.

### 2.5 차트·도식 표현

차트 없음. 도식 장치 5가지: ① 질문/답 말풍선 대화 ② 번호(❶❷❸) 목록 상자 ③ 굵기+밑줄 강조 ④ 검정 하이라이트 상자(닫는 인용) ⑤ 말풍선 안 이모지 1개. → 우리는 차트·도식을 **같은 자리(사진 자리)** 에 둔다.

### 2.6 글 밀도

| 항목 | 값 |
| --- | --- |
| 본문 글자(질문·답 제외) | 장당 ≈170~260자(공백 포함), 평균 ≈210자 ≈ **45~65 어절** |
| 질문·답 | 각 ≈12~22자 |
| 표지 | ≈14자 |
| 문단 | 장당 2~4개, 문장은 짧은 해요체, 한 문단 2~4줄 |

### 2.7 출처 · 브랜드 표기 위치

- **출처 표기 장·각주 없음.** 귀속은 문장 안에서 한다(「~를 근거로 보도된」, 「~ 말로는」, 인용부호).
- **기준 시점·날짜 표기 없음.**
- 계정 표시: 표지 하단 중앙 + 2~9장 우하단 상자(코너 밀착). 협업 로고·크레딧: 표지 상단에만.
- 페이지 번호·진행 표시 없음(앱의 점 표시에 의존).

### 2.8 장 넘김 장치

1. **호기심 사슬** — 각 장의 마지막 문단이 다음 장의 질문을 낳는다(질문이 곧 다음 장의 제목).
2. **고정 앵커** — 질문/답 말풍선 위치가 장마다 같아 넘길 때 눈이 같은 곳에 머문다.
3. **사진 톤 연속** — 소재·색조(벽돌·자연광)가 이어진다.
4. **끝 신호** — 마지막 장만 바탕을 종이색으로 바꾸고 닫는 인용을 검정 상자로 강조.
5. 화살표·「넘기세요」 문구·장 번호는 **쓰지 않는다**.

## 3. 우리에게 가져온 것 · 다르게 간 것

| 레퍼런스 구조 | 우리 카드 | 다르게 간 이유 |
| --- | --- | --- |
| 사진 + 흰 페이드 + 글 영역 | **도식·차트 자리(상단 ≈33 %)** + 글 영역 | 사진 자산·라이선스가 없고, 우리 가치는 사진이 아니라 **차트·경로 도식**이다 |
| Q/A 말풍선(둥근 모서리, 그림자, 이모지) | **직각 질문 상자(좌) + 강조색 답 띠(우)**, 이모지 없음 | 모양을 그대로 쓰지 않는다. 질문은 포맷 프리셋의 **단 질문**(5단 모두 질문형)이라 구조가 자연스럽게 맞는다 |
| 호기심 사슬 | 푸터 **「Next › 다음 단」** 한 줄 | 5단이 이미 질문 순서이므로 다음 단을 예고만 한다 |
| 굵기+밑줄 강조 | 같은 장치. **실선=조사 · 점선=직접 경험**(SoT) | 의미를 부여해 구분 표시와 겸용 |
| 번호 목록 상자 | ○ 시나리오 목록 · ◆ 경로 목록 | 구분 기호(■▲◆○)가 번호 역할 |
| 출처·시점 없음 | **카드마다 기준 시점**, 마지막에 **출처·구분 장** | SoT 필수(§5) — 레퍼런스에서 가장 크게 벗어나는 점 |
| 인물 인용·사례 | 인용·인물 없음. 닫는 상자는 「독자가 직접 확인할 것」 | 사실·해석 분리, 한 문장 한 종류. 투자 권유로 읽힐 인용 금지 |
| 마무리 = 인용 | 마무리 = 확인할 것(5단) → 출처 장 | ②이후 편이 이 5단을 닫는다(SoT §4.3) |
| 한국어 해요체 | **영어(프리셋 기본)** | 발행 언어는 미정 [결정 D10] |
