2. 역할별 대응 — 레퍼런스 ↔ 우리 A ↔ 우리 B

대응은 「가장 가까운 역할」 기준이다. 레퍼런스에는 차트·출처 장이 없어 5·7번 대응은 말풍선 구조와 글 영역 구조만 비교한다.

표지사진 전면 + 큰 제목 2줄(하단 1/3) + 계정 표시

2단 시장의 기대질문/답 + 사실 나열 + 인용 강조 (우리는 수치 자리표시 차트)
3단 시나리오질문/답 + 번호 목록 상자 (우리는 갈래 도식 + ○ 목록)
4단 파급 경로질문/답 + 비교 문단 (우리는 경로 도식)
5단 발표 뒤 확인 · 닫는 문장종이 바탕 마무리 + 검정 강조 상자 인용
