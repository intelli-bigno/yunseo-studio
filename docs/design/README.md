**추천: A** — 브랜드 인상 「차분함·안목·신뢰감」에 가장 가깝고, 세리프를 제목(큰 글자)에만 써서 폰 크기 가독 위험이 작다.
다만 이는 시스템 서체로 그린 시안에 대한 판단이다 — 실제 폰 화면(작은 크기)과 영어 제목에서의 확인은 **하지 않았다** [미검증]. 발행 언어(D10)가 영어로 정해지면 B 가 더 안전해질 수 있다.

## 두 안이 같이 지킨 규칙

- 색은 바탕·글자·보조 회색·선·강조 **1색**. 강조색은 시점·차이·종류 번호 같은 구조 표시에만 쓰고, 상승=초록·하락=빨강 같은 방향 색 관례는 쓰지 않는다.
- 표지 틀은 세 종류가 같고 종류 표시와 제목만 바뀐다. 하단에 채널명 자리와 **기준 시점**을 항상 둔다.
- 차트는 한 장에 한 메시지, 직접 라벨, 범례 없음(차이 설명 제외), 축·단위·출처·기준 시점 표기. 시안의 차트는 **수치 없는 개념도**다.
- 구분 표시(■ 사실 · ▲ 시장 반응 · ◆ 해석 · ○ 시나리오, 실선 밑줄=조사 · 점선 밑줄=직접 경험)는 색이 아니라 기호·밑줄이라 흑백에서도 같다.
- 릴스 표지의 점선(앱 UI 안전영역)은 가정값이다 [미검증].
