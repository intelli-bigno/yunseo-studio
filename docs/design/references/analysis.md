## 1. 결론

- 모은 레퍼런스에서 **브랜드 인상(차분함·안목·신뢰감·접근성)과 맞는 문법은 셋**으로 갈린다: ① 종이색·세리프·가는 선(편집국), ② 어두운 바탕·모노 숫자·얇은 선(터미널), ③ 흰 바탕·굵은 산세리프·큰 숫자·두꺼운 선(스위스 포스터).
- 셋 모두 **색을 늘리지 않고 1색 + 구조(선·크기)로 위계를 만든다.** 이는 06 문서 §5(「편 카드 색을 쓰지 않는다」)와 충돌하지 않는다. 반대로 칩마다 색을 다르게 쓰는 레퍼런스(#11, #34)는 쓰지 않는다.
- **추천: 안 1 Broadsheet** (§6). 결정은 3안 중 선택이다.

## 2. 수집 방법과 한계

- Aside(실제 로그인 프로필)의 배경 Agent 탭으로 Pinterest 검색 결과·핀 페이지를 **읽기만** 했다. 보드 만들기·저장·팔로우·반응·댓글은 하지 않았다. 로그인 벽·차단은 없었다.
- 검색어 12개: editorial dashboard ui · content calendar dashboard ui · newsroom cms interface design · finance terminal minimal ui · magazine admin panel ui · dark minimal dashboard ui · data editorial ui design · editorial calendar planner ui · publishing workflow approval ui · social media scheduler dashboard · financial data visualization editorial · serif typography dashboard ui. 각 검색에서 위로 훑어 후보 **402개**를 얻고(중복 제거), 번호를 붙인 대조표로 보고 **48개**를 골랐다.
- 선별 기준: ① 브랜드 인상과 맞는가 ② 06 문서의 화면(편성 캘린더·변수·작성·출처 편집기·이전↔이후·발행 대기열) 중 하나에 쓸 문법이 있는가 ③ 색이 많거나 장식이 큰 것은 제외(반면교사 2개만 표시: #11 #34).
- **한계**: 「editorial dashboard」 같은 검색어도 결과 대부분이 색이 많은 일반 SaaS 목업이었다 — 에디토리얼·연보·신문 문법은 `financial data visualization editorial`·`serif typography` 검색에서 나왔다. 검색 결과는 로그인 프로필의 추천에 따라 달라 **같은 결과가 재현되지 않을 수 있다**. 핀 48개 중 **원 출처 페이지가 있는 것은 21개**뿐이다(나머지는 Pinterest가 출처 링크를 주지 않아 업로더 이름만 기록). 이미지는 저장하지 않고 핀 CDN 주소만 기록했다. 「검색어」 칸은 처음 발견된 검색어다.
- 주제 태그 분포(복수 태그): 타이포 17 · 차트 12 · 캘린더 10 · 다크 10 · 표·밀도 7 · 대시보드 7 · CMS·검수 6 · 종이색 5 · 워크플로 1.

## 5. 방향 3안

세 안 모두 **같은 화면(편성 캘린더 + 이번 주의 변수 + 사건 후보함)** 을 같은 자리표시 데이터로 그렸다. 비교는 화면 한 장이 전부이며 나머지 화면은 선택 뒤에 확장한다.

| | 안 1 Broadsheet | 안 2 Terminal | 안 3 Swiss |
| --- | --- | --- | --- |
| 한 줄 | 조간 신문 편집국 | 다크 고밀도 데스크 | 숫자와 굵은 타이포 구조 |
| 바탕/글자/강조 | #F7F4EE / #151515 / #1F5F5B | #0E1011 / #ECE9E2 / #7CC8BD | #FFFFFF / #0E0E0E / #C2410C |
| 글자 대비(계산값, 바탕 대비) | 본문 16.6 · 보조 5.3 · 강조 6.7 | 본문 15.7 · 보조 7.2 · 강조 9.9 | 본문 19.3 · 보조 6.8 · 강조 5.2 |
| 제목·숫자 | 세리프 제목 + 큰 세리프 날짜 | 산세리프 + 모노 숫자 | 굵은 산세리프 + 매우 큰 날짜·주차 |
| 구획 | 가는 선·여백, 카드 없음 | 얇은 선의 표 + 패널 | 두꺼운 선·번호 블록(01·02·03) |
| 인상 | 차분함·안목·신뢰감 | 전문가 도구, 「간지」 | 선명함·접근성, 처음 보는 임팩트 |
| 약점 | 처음 보는 임팩트가 가장 약함 | 「금융 앱」 인상, 카드 표지(밝음)와 톤 차이 | 「안목」이 약함(B 와 같음), 정보량 감소 |

각 안의 레퍼런스 번호·가져올 점은 시안 HTML 아래 메모와 [무드보드](moodboard.html) 필터에 있다. 상태 칩 규칙(06 §5: 검정=게이트 대기·막힘, 흰색=진행·완료)과 구분 기호(■▲◆○)는 세 안 모두 그대로 지켰다.

## 6. 추천과 이유

**추천: 안 1 Broadsheet.**

- 브랜드 인상 네 가지 중 「차분함·안목·신뢰감」과 가장 가깝다 — 세리프·가는 선·큰 세리프 날짜는 매거진·연보 레퍼런스(#6 #38 #40 #42 #43)와 같은 문법이다.
- 기존 추천 시각 시스템 A와 한 계열이라 **표지(카드)와 대시보드가 한 브랜드로 보인다.** 안 2는 톤 차이가 크고, 안 3은 B 쪽이다.
- 「간지」는 **큰 세리프 날짜 숫자·신문 마스트헤드·선**으로 낸다(안 1 시안의 날짜 숫자와 상단 마스트). 처음 임팩트가 약하다는 비용은 남는다.
- 선택 뒤 확장: 안 2는 **다크 테마**로(#18 라이트/다크 한 쌍 근거), 안 3의 번호 블록(01·02·03)은 종류 구분을 더 세게 하고 싶을 때 안 1에 빌려 쓸 수 있다.

## 7. 기존 시각 시스템 A·B와의 관계

시각 시스템은 [시안 A·B](../README.md)로 **카드·표지**를 위한 것이고, 이 문서의 3안은 **대시보드(운영 화면)** 를 위한 것이다. 대시보드는 브랜드 표면이 아니라 운영자 도구이므로 표지와 같을 필요는 없지만, 같은 계열이면 미리보기·승인 화면에서 표지를 바로 대조하기 쉽다.

| 3안 | 관계 | 달라지는 점 |
| --- | --- | --- |
| 안 1 | **A 의 앱 화면 확장** — 바탕·글자·강조 색을 A 그대로 | 큰 세리프 날짜, 신문 마스트, 후보함·변수 레일 같은 앱 구조 추가 |
| 안 2 | A 의 청록을 **어두운 바탕용으로 밝힌 색**(#7CC8BD) + 새 축(다크) | 표지 미리보기는 밝은 영역으로 분리해야 함 |
| 안 3 | **B 의 확장** — 바탕·글자·강조 색을 B 그대로, 01·02·03 번호 블록도 B 의 표지 규칙 | 날짜·주차를 그래픽 크기로, 굵은 구조선 |

선택에 따라 [D5 서체]·[D9 UI 언어]·[D10 발행 언어]가 시안에 영향을 준다 — 안 1은 세리프 한영 혼합 굵기가, 안 3은 굵은 한글 서체 선택 폭이 확인 대상이다.

## 8. 미검증·남은 것

- 시안은 macOS 시스템 서체로 그린 **정적 한 화면**이다. 다른 기기에서 HTML을 열면 서체가 달라질 수 있으며 PNG(2000 px 폭 = 1600 px × 1.25)가 기준이다.
- 실제 폰·작은 화면 확인, 월 보기·편 상세·출처 편집기 화면은 **하지 않았다.** 방향 선택 뒤 같은 문법으로 확장한다.
- 다크(안 2)의 장시간 가독, 한글 모노 혼합 폭은 확인하지 않았다 [미검증].
- 썸네일은 Pinterest 이미지 주소를 그대로 불러오므로 시간이 지나면 깨질 수 있다. 핀 링크·pins.json 이 기록이다.
- 이미지의 권리는 각 제작자에게 있다. 이 폴더는 **내부 참고용**이며 외부에 공개·재배포하지 않는다.
