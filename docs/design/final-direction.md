# 대시보드 최종 방향 — 「Private Ledger」 (2026-11-04)

**내부 참고 전용.** 레퍼런스 이미지는 참고만 했고 복제하지 않았다. 구현: `packages/design-tokens` + `apps/dashboard`.

## 1. 결론

- 사용자 지시(2026-11-04): 「개인용 카드뉴스·콘텐츠 제작 스튜디오 대시보드 — 있어 보이고, 남성 비즈니스 오너의 돈 많은 간지, 댄디·컴팩트·그럴듯하게. 단 직관적이고 사용하기 편해야 됨」.
- **선행 3안 중 안 2(Terminal)의 다크 바탕·모노 숫자 + 안 1(Broadsheet)의 세리프 제목·큰 세리프 날짜·가는 선 구획을 합치고, 안 3(Swiss)의 01·02·03 번호 블록만 빌려** 최종 1안으로 확정했다. 이름은 「Private Ledger」(개인 원장).
- 한 줄 인상: 웜 차콜 가죽 다이어리 + 크림 글자 + 황동(brass) 한 점. 시계 브랜드 에디토리얼처럼 여백·세리프·번호로 위계를 만들고, 색은 늘리지 않는다.

## 2. 왜 이 조합인가 (기존 가정 → 근거 → 결론)

| 기존 가정 | 근거 | 결론 |
| --- | --- | --- |
| 추천은 안 1(종이색 Broadsheet) — 차분함·안목 | 이번 지시의 축은 「남성 오너의 고급감·댄디」. 새 수집 313개 중 이 축의 레퍼런스(프라이빗 뱅킹·시계 에디토리얼·차콜/황동 팔레트)는 **거의 전부 어두운 바탕 + 금속 1점**이었다(아래 #1~#30) | 바탕은 안 2 의 다크로 바꾼다 |
| 안 2 는 「금융 앱」 인상 | 금융 앱 인상의 원인은 다크가 아니라 **형광·글로우·다색 차트**였다(반면교사 3개). 세리프 큰 숫자(#8 #16)·에디토리얼 여백(#11 #15)을 얹으면 「앱」이 아니라 「원장」으로 읽힌다 | 안 1 의 세리프 제목·큰 날짜·선 구획을 그대로 가져온다 |
| 안 2 약점: 밝은 카드 표지와 톤 차이 | 시계 카탈로그(#13)처럼 **크림 종이 틀** 안에 표지를 놓으면 다크 화면에서도 표지 색이 그대로 보인다 | 미리보기만 종이 틀(`paper`) |
| 안 3 은 안목이 약함 | 번호 단(#15 #17 #18)은 남성 에디토리얼의 핵심 문법이다 | 종류 표시(01 이전 · 02 이후 · 03 연구)와 메뉴 번호로만 빌린다 |
| 「간지」는 장식으로 낸다 | 레퍼런스의 고급감은 장식이 아니라 **절제**(색 1개·직각 모서리·넓은 자간 라벨·큰 숫자 하나)에서 나왔다 | 그림자·그라디언트·유리 효과 없음, 모서리 2~4 px |
| 「직관적」은 별도 과제 | 06 문서의 정보구조(메뉴 6개·편 상세 탭 = 한 편의 길)가 이미 클릭 2번 구조다 | 구조는 그대로, 단축키·빠른 이동만 더한다 |

[미검증] 실제 사용자(최윤서)의 취향 확인은 하지 않았다 — 지시는 사용자(의뢰자)가 했다.

## 7. 미검증·남은 것

- 데이터는 전부 목업(자리표시)이며 저장은 화면 상태뿐이다 — 유스케이스 연결은 M2.
- 한글 서체 두 개는 웹폰트 용량이 크다(빌드 시 분할 파일로 자체 호스팅). 첫 로딩 체감은 재지 않았다.
- 카드 v2 렌더는 아직 저장소 밖(Windows 산출물 폴더)에 있다 — 저장소에 들어오면 `cards.ts` 의 v2 경로를 저장소 경로로 바꾼다.
- 실제 폰·태블릿 폭은 확인하지 않았다(노트북 1440 기준).
