운영 대시보드 와이어프레임 — 저충실도

채널명·발행 언어·최종 시각은 미정이라 자리표시입니다. 문구는 구조를 보여 주는 가짜 글이고, 사건명·날짜·수치는 실제 값이 아닙니다. 색은 쓰지 않았고 파란 번호는 설명용 주석입니다. 이 화면들이 쓰는 데이터 규칙은 docs/01-content-sot.md §4~6, 공정은 docs/02-sop.md.

■ 사실▲ 시장 반응◆ 해석○ 시나리오 실선 밑줄 = 조사점선 밑줄 = 직접 경험 게이트 = 사람이 통과해야 다음으로 감 (G1 주제·관점 / G2 사실 확인 / G3 최종 발행 판단)

왼쪽 메뉴 6개. 편 상세는 한 화면 안의 탭 6개로 흐름 그대로 이어진다.
