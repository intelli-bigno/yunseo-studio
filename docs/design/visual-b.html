시안 B — Signal (선명한 산세리프 · 블록)

굵은 산세리프 제목 · 흰 바탕+검정 블록 · 번트오렌지 1색. 채널명·핸들·서체·강조색은 미정이라 자리표시이고, 사건명·날짜·수치는 실제 값이 아닙니다(○○·MM.DD·「수치 없음」). 카드는 실제 1080×1350 의 1/3 크기(360×450), 세로 영상은 1080×1920 의 1/4(270×480) 입니다. 서체는 시스템 서체로 그린 시안이며 최종 서체는 결정 D5 입니다.

시각 시스템 시안 · 2안 중 B안

1. 기본 요소

색은 바탕·글자·보조 회색·선·강조 1색까지만. 강조색은 「시점」「차이」「종류 번호」처럼 구조를 알려 주는 곳에만 쓰고, 상승·하락을 가르는 빨강·초록 관례는 쓰지 않는다(시나리오가 한쪽으로 기울어 보이지 않게).

색 (프리셋 brand.palette 에 들어갈 후보)

바탕#FFFFFF
글자#0E0E0E
보조#666666
선#E2E2E2
강조 1색#C2410C

  • 보조 회색 / 바탕 — 5.7:1
  • 강조(번트오렌지) / 바탕 — 5.2:1

대비는 WCAG 계산식으로 직접 계산한 값(≥ 4.5:1 이 본문 기준).

서체 역할

세계의 변화에서, 시장의 다음 질문을 찾습니다.
본문·캡션·차트 글자는 같은 산세리프. 숫자는 폭이 같은 숫자(tabular)로 정렬합니다. 0123456789 MM.DD

이 안을 고르는 이유 · 위험

  • 「선명한 타이포」「접근성」에 가장 직접적이다 — 굵은 산세리프 한 가지로 한·영 모두 같은 인상을 낸다.
  • 검정 블록(푸터·번호 칸)이 표지의 틀을 만들어 「일관된 표지」가 가장 눈에 띈다. 프로필 격자에서 한눈에 구분된다.
  • 프리셋 잠정값(흰 바탕·검정 글자·회색)과 같은 뼈대라 바꿀 것이 강조색뿐이다.

위험·미확인

  • 매거진다운 「안목」 인상은 A 보다 약하고 뉴스·금융 앱처럼 보일 수 있다.
  • 굵은 블록이 많아 한 장 안의 글자 양이 늘면 답답해진다 — 글자 수 상한을 더 보수적으로.
