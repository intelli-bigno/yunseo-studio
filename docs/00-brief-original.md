# 00. 확장 브리프 원문 (보존 파일 — 기존 문구 수정 금지, 덧붙이기만)

- 출처: 지시 관제가 전달한 작업 명세(2026-11-04), 「사용자 친구 원문 요지」. 문구는 전달받은 그대로 두었다.
- 이 파일은 기존 문구를 고치지 않고 덧붙이기만 한다(최종 브리프 추가분은 맨 아래). 해석·정리는 [01-content-sot.md](01-content-sot.md), 공정은 [02-sop.md](02-sop.md), 판단이 갈리는 곳은 [08-decisions.md](08-decisions.md).

## 브리프

컨셉 「세계의 변화와 시장을 연결하고, 다가올 사건의 파급효과를 미리 짚는 투자 매거진」, 핵심 문장 「세계의 변화에서, 시장의 다음 질문을 찾습니다.」 주요 경제·정치 이벤트의 시나리오·시장 영향, 트레이딩 관점·연구를 다루고 자료 조사에 운영자 도메인 지식·경험을 더해 고유 해석을 쌓는다.

## 브랜딩

최우선 목표=팔로우하고 싶은 매체(팔로워가 좋은 정보원을 알고 흐름을 읽고 자기 관점으로 판단하는 사람처럼 느끼게). 인상=차분함·안목·신뢰감·접근성, 읽기 쉽되 새 연결·생각할 거리. 알파는 선별·해석 깊이로. 금지 표현 「무료」「수익 보장」「비밀 정보」「무조건」, 「지표」는 브랜드 전면 홍보 문구 금지. 시각=절제된 색·선명한 타이포·읽기 쉬운 차트·일관된 표지.

## 목표·타겟

초기=프로필·최근 게시물만으로 관점·취향이 느껴져 팔로우, 이후=사건 전후 분석·연구로 재방문·저장·공유 이유. 타겟은 국가가 아닌 관심사·태도(경제·정치·시장 흐름 관심, 자기 판단 기준을 만들고 싶은 독자). 한국 한정 아님. 발행 언어는 미정 — 프리셋 값으로 두고 기본값은 영어(이전 전달)로 표시.

## 핵심 콘텐츠

①이슈 이전: CPI·FOMC·선거·주요 정책 발표·예정 연설 등 기대를 바꿀 사건 선별, 기본 전날 발행·복잡한 사건은 앞서 배경 설명. 구성 5단=왜 중요한가 / 현재 시장은 무엇을 예상하는가 / 결과별 시나리오 / 어떤 경로로 자산·업종에 영향 / 발표 이후 무엇을 확인할 것인가. ②이후 포맷(사건 이후 분석·연구)은 자리만 둔다.

## 이번 기본 셋팅 범위 (같은 명세의 지시 부분)

①docs 의 SoT·SOP 를 위 브리프로 갱신(원문 보존 파일 1개 + 정리본) ②프리셋 파일(브랜드명·캐릭터·톤·언어·색·서체 — 이름 미정 자리표시자) ③금지 표현 검사 규칙(데이터 + 테스트) ④설계대로 모노레포 골격(apps/·packages/ 경계, 도메인·유스케이스·어댑터 계층 빈 모듈, 워크스페이스·린트·테스트·CI 최소 설정) ⑤콘텐츠 정본 스키마(이슈 이전 5단 카드) + 예시 1건(미국 중간선거 이후 시장이 다시 계산할 세 가지, 사실 수치는 넣지 않음).

금지: 게시 자동화·외부 계정(Instagram·YouTube) 접속, 비용 발생, Linear, 비밀값, 투자 권유·수치 단정 문구, noa 코드·자산 반입.

## 최종 브리프 추가분 (2026-11-04, 사용자 친구의 최종 브리프 7절 — 지시 관제가 전달한 그대로)

이전 브리프 1~4절(컨셉·브랜딩·목표/타겟·①이슈 이전 5단)은 위 원문과 같다. 아래는 추가분이다.

②이슈 이후 「무엇이 달라졌는가」: 실제 결과를 사전 시나리오와 연결 — 실제 결과와 예상의 차이 / 확인된 시장 반응 / 유지되거나 달라진 판단 근거 / 다음으로 확인할 변수. 충분한 자료 확보 뒤 발행, 보도된 사실·시장 반응·운영자 해석을 구분.

③트레이딩 연구 「어떻게 판단하고 실행할 것인가」: 이슈 없는 날 매매 방법·시장 구조·리스크 관리·판단 과정과 복기, 운영자 자료·직접 개발 도구 소개·공개. 한 주제를 아이디어 → 적용 조건 → 실패 사례 → 도구와 사용법 → 후속 검증으로 발전, 배포 홍보보다 게시물에서 먼저 가치 제공. 기획 제목 예 「미국 중간선거 이후, 시장이 다시 계산할 세 가지」.

5 운영: 피드 하루 1개(중요 사건 전후 우선, 나머지 날 트레이딩 연구), 스토리·하이라이트 「이번 주의 변수」 주 1회(날짜 명확), 릴스 주 1~2개(시각 설명 좋은 피드 주제 확장). 발행량 채우려 작은 사건 확대 금지, 중요도·자료 확보로 편성 조정.

6 제작·신뢰: 자료 수집·일정 정리·초안·디자인은 가능한 범위 자동화, 운영자는 주제 선정·핵심 관점·사실 확인·최종 발행 판단. 출처·기준 시점 표시, 사실·해석·시나리오 구분, 직접 경험·조사 내용 구분, 분석이 달라지면 후속에서 수정 이유 설명, 도구·연구에는 적용 조건·한계·실제 검증 범위 제시.

7 팔로우 이유: 다가올 사건을 미리 생각하고, 결과 뒤 판단을 점검하며, 평소엔 직접 활용할 관점과 도구를 쌓는다 — 「좋은 소스를 알고, 시장을 자기 관점으로 읽는 사람들의 매거진」. 채널명·발행 언어·최종 시각 디자인은 이 방향 기준으로 나중에 확정.

## 이번 명세의 지시 부분 (같은 전달문)

SoT·SOP 할 일: 콘텐츠 3종(이전·이후·연구) 스키마와 이전↔이후 연결, 사실/해석/시나리오·경험/조사 구분 필드, 출처·기준 시점 필수, 수정 이력(정정 이유), 편성 규칙(피드·스토리·릴스 주기, 중요도 판정), 자동화/운영자 책임 경계, SOP 단계별 체크리스트·사람 게이트.

UI/UX 할 일: 대시보드 정보구조·화면 흐름(편성 캘린더, 이번 주의 변수, 콘텐츠 3종 작성·검수 화면, 출처·구분 표시 편집기, 이전↔이후 연결 보기, 발행 대기열) 와이어프레임 + 카드뉴스·표지·스토리·릴스 표지 시각 시스템 시안 2안(절제된 색·선명한 타이포·읽기 쉬운 차트·일관된 표지, 이름 미정 자리표시). 정적 HTML/PNG 시안을 docs 에 두고 보고에 경로.
